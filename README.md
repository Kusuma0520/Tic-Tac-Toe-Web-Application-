# Tic-Tac-Toe-Web-Application-
# ❌⭕ Tic-Tac-Toe Web Application

## 📌 Task Overview

This project is an **interactive Tic-Tac-Toe web application** built using HTML, CSS, and JavaScript.

Players can:

* Play against another player (2-player mode)
* Click cells to make moves
* Automatically detect win/draw conditions

---

## 🚀 Features

* 🎮 2-player gameplay (X vs O)
* 🧠 Win detection logic
* 🤝 Draw detection
* 🔄 Reset game functionality
* 📱 Responsive and simple UI

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Grid Layout)
* JavaScript (DOM Manipulation)

## ⚙️ How It Works

### 🔹 Game Logic

* Board is stored as an array of 9 elements.
* Each click updates the board and UI.

### 🔹 Win Detection

* Checks predefined winning combinations.

### 🔹 Draw Detection

* If all cells are filled and no winner → Draw.

### 🔹 Reset Function

* Clears board and restarts the game.
